4 Charleston myths that trip up beginners.

Know the real passes before your next mahj night.

MYTH
Don't need that joker? Pass it.
THE RULE

Jokers never go in the Charleston.

Keep every joker you're dealt. Pass something else.

MYTH
You always do two Charlestons.
THE RULE

The second one only happens if all four agree.

If it does, it runs in reverse: left, across, right.

MYTH
You can blind pass on any pass.
THE RULE

Only on the last pass of each Charleston.

That's the first left and the second right. It's still 3 tiles.

MYTH
The courtesy pass is always 3 tiles.
THE RULE

Anywhere from 0 to 3.

You and the player across from you agree on the number.
